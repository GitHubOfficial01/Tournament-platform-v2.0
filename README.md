## 🎯 О проекте

Турнирная платформа создана для автоматизации проведения интеллектуальных игр, таких как "Математическая биржа". Система позволяет:

- 📊 Отслеживать результаты турниров в реальном времени
- 👨‍⚖️ Жюри быстро вводить результаты с автоматическим подсчетом баллов
- 🗂️ Организаторам создавать и управлять турнирами
- 🔐 Защищать доступ к вводу результатов паролями турниров

## ✨ Функциональность

### Для всех пользователей
- Просмотр списка доступных игр
- Просмотр турниров по каждой игре
- Табло результатов в трех видах:
  - Все протоколы с фильтрацией по командам
  - Сводная таблица по задачам
  - Текущее табло с сортировкой по баллам
- Инструкция к игре "Математическая биржа" (онлайн-просмотр)

### Для организаторов
- Создание новых турниров
- Генерация паролей для доступа жюри
- Просмотр только своих турниров
- Удаление своих турниров
- Мониторинг количества введенных результатов

### Для жюри
- Вход в систему по логину/паролю
- Доступ к турнирам только по паролю турнира
- Ввод результатов:
  - Выбор команды (с автодополнением)
  - Номер задачи
  - Ставка команды
  - Вердикт (правильно/неправильно)
- Автоматический подсчет баллов
- Проверка достаточности баллов при отрицательном вердикте
- Просмотр текущих счетов команд
- Быстрый ввод для часто используемых команд

## 🛠 Технологии

- **Backend**: Python 3.8+, Flask
- **Аутентификация**: Flask-Login
- **Хранение данных**: JSON файлы
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Стилизация**: Font Awesome иконки
